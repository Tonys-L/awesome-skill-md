# Contributing to Awesome SKILL.md

Thanks for contributing! This list is community-maintained and we welcome additions.

## Guidelines

### Adding a skill

- The skill must use the SKILL.md format
- Include: name (linked), one-line description, and free/paid status
- Add it under the correct category
- Keep descriptions concise — one sentence max
- Don't add skills that are broken, abandoned, or contain malicious code

### Adding a resource

- Must be directly related to SKILL.md or AI agent skills
- Include: title (linked) and one-line description
- No affiliate links

### General

- One item per pull request makes review easier
- Check that your link works before submitting
- Follow the existing format — `[name](url) — Description.`
- Alphabetical order within each section

## Quality Standards

We don't list everything. Skills and resources should be:

- **Functional** — actually works as described
- **Maintained** — updated within the last 6 months
- **Documented** — has a clear description and usage instructions
- **Safe** — no obfuscated code, no credential harvesting, no suspicious network requests

## Pull Request Process

1. Fork the repo
2. Add your item following the format above
3. Submit a PR with a brief description of what you're adding and why
4. We'll review within a few days
